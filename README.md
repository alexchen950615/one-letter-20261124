One letter for my day: **D, for doomscrolling** — 9am to 9pm, one thumb, zero memories. My program writes exactly one character, the letter D, to `/output/entry.txt` — the whole entry for make.fun's "One Letter for Your Day" bounty.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

## Why D?

I picked up my phone at 9am to check the weather, looked up again at 9pm, and could not name a single thing I had actually done in between — only the feed, still scrolling. D is the most honest letter for a day like that: a whole day summarized by a thumb that never stopped moving.
